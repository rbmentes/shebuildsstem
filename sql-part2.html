PART 2

Filtering & Sorting

Beginner-friendly · WHERE · ORDER BY · LIMIT

In Part 1 we wrote our first SELECT query with a basic WHERE clause. Now let's dig into everything WHERE can actually do, then learn to control the order and quantity of what comes back with ORDER BY and LIMIT.

🎯 Comparison operators

The WHERE clause filters rows using comparison operators, just like in most programming languages:

OperatorMeaning
=equal to
!= or <>not equal to
> / <greater than / less than
>= / <=greater than or equal / less than or equal
SELECT name, gpa
FROM students
WHERE gpa >= 3.7;

This returns only students with a GPA of 3.7 or higher.

🔗 Combining conditions: AND, OR, NOT

Real filters usually need more than one condition. AND requires both to be true, OR requires at least one, and NOT flips a condition.

SELECT name, major, gpa
FROM students
WHERE major = 'EEE' AND gpa > 3.5;

Watch your parentheses

When mixing AND and OR, always use parentheses to make the logic explicit — major = 'EEE' AND (gpa > 3.5 OR year = 4) means something different than the same clause without parentheses, and SQL's default order of operations may not match what you intended.

🧮 Useful filtering keywords

BETWEEN checks a range, IN checks against a list of values, and LIKE matches text patterns.

WHERE gpa BETWEEN 3.0 AND 3.8
WHERE major IN ('EEE', 'Computer Science')
WHERE name LIKE 'B%'

In a LIKE pattern, % matches any number of characters, so 'B%' matches any name starting with "B." An underscore _ matches exactly one character.

To check for missing data, use IS NULL or IS NOT NULL — never = NULL, since NULL represents "unknown" and doesn't equal anything, not even itself.

↕️ Sorting results: ORDER BY

ORDER BY sorts your results by one or more columns. Add ASC for ascending (the default) or DESC for descending.

SELECT name, gpa
FROM students
ORDER BY gpa DESC;

You can sort by multiple columns too — SQL sorts by the first column, then uses the second to break ties:

SELECT name, major, gpa
FROM students
ORDER BY major ASC, gpa DESC;

✂️ Limiting rows: LIMIT

LIMIT caps how many rows come back — handy for previewing data or grabbing just the "top N" results.

SELECT name, gpa
FROM students
ORDER BY gpa DESC
LIMIT 3;

This returns only the top 3 students by GPA. Combining ORDER BY with LIMIT is one of the most common patterns in SQL — think "top 5 best-selling products" or "10 most recent orders."

💡 Final takeaway

You can now filter rows with comparison and logical operators, match ranges, lists, and text patterns, sort results with ORDER BY, and cap them with LIMIT. In Part 3, we'll learn to summarize data across many rows at once with GROUP BY and aggregate functions like COUNT, SUM, and AVG.
