Object Detection — What's YOLO?

Beginner-friendly · Object Detection · Real-Time Vision

In Part 2, our CNN answered one question per image: "what is this?" But real photos usually contain more than one thing. Object detection answers a harder question: what objects are here, and where exactly is each one? This is where architectures like YOLO come in.

🔍 Classification vs. detection

Classification (Part 2)

One label for the whole image: "dog." Doesn't say where, or how many.

Detection (this post)

A box around each object, plus a label: "dog at (x, y, w, h)," possibly several times per image.

Detection models output a list of bounding boxes — rectangles that mark where each object is — along with a class label and a confidence score for every box.

🐌 The old way: sliding windows

Early approaches ran a classifier over hundreds of small crops of the image at different positions and sizes, asking "is there an object here?" at every single one. It worked, but it was painfully slow — far too slow for anything real-time, like video or a self-driving car's camera feed.

Better versions like R-CNN improved accuracy by first proposing a smaller set of likely regions, then classifying just those. Still, running the network many times per image kept things slow.

⚡ YOLO: You Only Look Once

YOLO's key idea is right there in the name: instead of scanning the image piece by piece, it looks at the entire image exactly once and predicts every bounding box and class in a single pass through the network.

  • 1

    The image is divided into a grid — say, 13×13 cells.

  • 2

    Each cell predicts: "is the center of an object here, and if so, what box and what class?"

  • 3

    All predictions come out of the network together, in one forward pass.

  • 4

    Overlapping, low-confidence boxes are filtered out with a step called Non-Maximum Suppression, leaving the best box per object.

Why "one look" matters

Because YOLO processes the whole image in a single network pass rather than hundreds of separate crops, it can run at real-time speeds — fast enough for live video, robotics, and camera feeds, not just still photos.

📦 What a prediction actually looks like

For each detected object, YOLO outputs something like:

class: "cat", confidence: 0.87, box: (x=112, y=45, w=80, h=95)

The box coordinates mark the top-left corner plus width and height, the class is the predicted label, and the confidence score tells you how sure the model is — low-confidence boxes are usually thrown away before showing results.

⚖️ Speed vs. accuracy trade-offs

Model familyApproachBest for
Sliding window / R-CNN familyMultiple passes, region proposalsHighest accuracy, offline processing
YOLOSingle pass over the whole imageReal-time speed, video, embedded devices

Newer YOLO versions have closed much of the accuracy gap while keeping their speed advantage, which is why the family remains a go-to choice for real-time detection tasks.

💡 Final takeaway

Object detection extends classification by locating every object, not just naming one. YOLO's "look once" design predicts all boxes and classes in a single forward pass, trading a little accuracy for the real-time speed that made it a default choice in production vision systems.
