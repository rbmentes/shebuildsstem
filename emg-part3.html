🔊 Step 1 — Bandpass filtering

A bandpass filter passes frequencies within a specified range and blocks everything outside. For EMG, the useful muscle signal energy lives between 20 Hz and 450 Hz. Everything below 20 Hz is motion artifact and DC offset. Everything above 450 Hz is high-frequency noise and aliasing.

EMG bandpass filter — what gets kept and what gets removed
Below 20 Hz (blocked)
Motion artifacts
20 – 450 Hz (passed)
Muscle signal ✓
Above 450 Hz (blocked)
HF noise
Python — Butterworth bandpass filter from scipy.signal import butter, filtfilt import numpy as np def bandpass_filter(signal, lowcut=20, highcut=450, fs=1000, order=4): """ Apply a zero-phase Butterworth bandpass filter to EMG signal. fs = sampling rate (Hz) lowcut = lower cutoff frequency (Hz) highcut = upper cutoff frequency (Hz) order = filter order (4 is standard for EMG) """ nyq = fs / 2 # Nyquist frequency low = lowcut / nyq # normalise to [0, 1] high = highcut / nyq b, a = butter(order, [low, high], btype='band') # filtfilt applies filter forwards AND backwards — zero phase distortion return filtfilt(b, a, signal, axis=0) # Example usage raw_emg = np.random.randn(5000, 8) # 5 seconds, 8 channels, 1000 Hz filtered_emg = bandpass_filter(raw_emg, fs=1000) print(f"Filtered shape: {filtered_emg.shape}") # (5000, 8)

🪟 Step 2 — Windowing (segmentation)

We can't feed the entire signal to a model at once. Instead we slice it into short overlapping windows. Each window becomes one training sample. The key parameters are window size (how long each segment is) and stride (how much we move between windows):

Sliding window segmentation — 200ms windows, 100ms stride (50% overlap)
Python — sliding window segmentation def create_windows(signal, label, window_size=200, stride=100): """ Slice a filtered EMG signal into overlapping windows. window_size = number of samples per window (200ms @ 1000Hz = 200 samples) stride = step between windows (100 samples = 100ms) Returns list of windows and corresponding labels. """ X, y = [], [] for start in range(0, len(signal) - window_size, stride): end = start + window_size window = signal[start:end, :] # shape: (200, 8) X.append(window) y.append(label) return X, y # Example: 5 gestures × 5 seconds × 1000 Hz → windowed samples windows, labels = create_windows(filtered_emg, label=0) print(f"Windows: {len(windows)}, each shape: {windows[0].shape}") # Windows: 48, each shape: (200, 8)

📐 Step 3 — Feature extraction

We could feed raw windowed samples directly to a deep learning model — and for a TCN or CNN that works well. But for classical ML models, and to reduce dimensionality, we extract handcrafted features from each window. These are compact numerical summaries that capture the most important characteristics of the EMG signal:

RMS

Root Mean Square — overall signal power

RMS = √( (1/N) × Σ x²[n] )

The most widely used EMG feature. RMS reflects the power of the signal and correlates strongly with muscle force level. A high RMS means the muscle is contracting strongly. Used in almost every EMG gesture recognition system.

MAV

Mean Absolute Value — average activation level

MAV = (1/N) × Σ |x[n]|

Similar to RMS but computationally cheaper. Measures the average rectified amplitude of the signal. Good indicator of muscle activation intensity and is robust to short-duration spikes.

ZCR

Zero Crossing Rate — frequency information

ZCR = Σ |sign(x[n]) - sign(x[n-1])| / 2

Counts how many times the signal crosses zero per window. Higher ZCR means higher frequency content. Different gestures produce different frequency patterns in the EMG signal — ZCR captures this without a full FFT.

VAR

Variance — signal spread and variability

VAR = (1/N-1) × Σ (x[n] - μ)²

Measures how much the signal varies around its mean. High variance indicates strong muscle activity with variable intensity — characteristic of dynamic movements like finger flexion or wrist rotation.

Python — extract all 4 features per channel per window def extract_features(window): """ Extract RMS, MAV, ZCR and Variance from each channel of a window. window shape: (200, 8) → output: 32 features (4 per channel × 8 channels) """ features = [] for ch in range(window.shape[1]): # loop over each electrode channel sig = window[:, ch] # RMS — root mean square rms = np.sqrt(np.mean(sig ** 2)) # MAV — mean absolute value mav = np.mean(np.abs(sig)) # ZCR — zero crossing rate zcr = np.sum(np.diff(np.sign(sig)) != 0) # VAR — variance var = np.var(sig) features.extend([rms, mav, zcr, var]) return np.array(features) # shape: (32,) # Apply to all windows all_features = [extract_features(w) for w in windows] X_features = np.array(all_features) print(f"Feature matrix shape: {X_features.shape}") # (48, 32) → 48 windows × 32 features each

📊 What the feature vector looks like

For one 200ms window with 8 EMG channels, the feature extraction gives us a 32-dimensional vector — 4 features × 8 channels. This is what gets passed to the classifier:

Example feature vector — one window, channel 1 (fist gesture)
0.621RMS ch1
0.508MAV ch1
87ZCR ch1
0.385VAR ch1
0.043RMS ch2
0.031MAV ch2
12ZCR ch2
0.002VAR ch2

Channel 1 (flexor) shows high activity — fist gesture. Channel 2 (extensor) is quiet. This pattern is exactly what the model learns to recognise.

💡 Key takeaways from Part 3

Raw EMG is useless until it's processed. The preprocessing pipeline — bandpass filter to remove noise, sliding windows to segment in time, feature extraction to summarise each window — transforms a messy biological signal into a clean structured dataset that a machine learning model can actually learn from. These three steps are the foundation of every EMG-based AI system, including the gesture classifier we built earlier in this series.
